# ScanFace

ระบบต้นแบบตามโจทย์: อัปโหลดรูปอาจารย์เพียง 1 รูป แล้วค้นหารูปจากเว็บไซต์มหาวิทยาลัยสวนดุสิต พร้อมแสดงกรอบสีเหลืองบนใบหน้าที่ตรวจพบ

รัน `python server.py` แล้วเปิด `http://localhost:8004/` จากนั้นกด “สร้างฐานข้อมูลรูปทั้งเว็บไซต์” ครั้งแรก ระบบจะเก็บ embedding ของใบหน้าจากเว็บไซต์ไว้ใน `face_index.json` และใช้รูปต้นแบบค้นหาอาจารย์คนต่อไปได้

ระบบใช้โมเดล YuNet + SFace สำหรับตรวจจับและเปรียบเทียบใบหน้า รูปต้นแบบจะถูกประมวลผลในเครื่อง ไม่ได้บันทึกลงฐานข้อมูล

## ดึงรูปเก็บไว้ในเครื่องก่อนสแกน

รัน `python download_images.py` รูปจะถูกเก็บไว้ในโฟลเดอร์ `downloaded_images` และรายการ URL ต้นทางจะอยู่ใน `downloaded_images/metadata.json`
